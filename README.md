# Amber-Store Core (Rust)

A content-addressable store for **filesystem trees** — the Rust port of
[`github.com/jobs-build/amber-store-core`](https://github.com/jobs-build/amber-store-core),
intended to be embedded as a library in other Rust projects.

> **Status:** work in progress; byte-compatibility with the Go implementation
> is the driving requirement. See [`PORTING.md`](PORTING.md) for the
> compatibility contract and [`VECTORS.md`](VECTORS.md) for the
> cross-implementation golden vectors. The format is specified in
> [`architecture/`](architecture/).
